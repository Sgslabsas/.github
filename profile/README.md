# SGS Labs AS

Vi utvikler programvare og skreddersydde løsninger for bedrifter og organisasjoner.

SGS Labs er et norsk selskap som lager digitale verktøy for arbeidsflyter som standardsystemene ikke dekker godt nok. Vi følger løsningen hele veien, fra første idé til ferdig produkt i drift.

## Hva vi lager

- **Webapplikasjoner:** nettbaserte systemer som brukes i det daglige arbeidet
- **Fagsystemer:** løsninger tilpasset én bransje, for eksempel bemanning, booking og medlemsdrift
- **Integrasjoner:** kobling mot andre systemer, blant annet regnskapssystemer
- **Videreutvikling og drift:** oppfølging av løsningene etter at de er satt i bruk
